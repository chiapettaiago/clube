1. INTRODUÇÃO

1.1 Sobre o Sistema

O Sistema de Clube é uma plataforma completa para gestão de clubes, associações e condomínios. Permite o cadastro de sócios, emissão de carteirinhas com QR Code, controle de convites, gestão financeira e muito mais.

1.2 Principais Funcionalidades

FuncionalidadeDescrição
👥 Cadastro de SóciosCadastro completo com foto, dados pessoais e vínculos familiares
🎫 Carteirinhas DigitaisGeração de carteirinhas com QR Code ou código de barras
👨‍👩‍👧‍👦 Controle FamiliarDependentes vinculados ao sócio principal, convites compartilhados
🎟️ Sistema de ConvitesConvites mensais compartilhados por família
📊 RelatóriosExportação de dados e gráficos estatísticos
🎨 PersonalizaçãoCores por tipo de sócio, marca d'água personalizada
🔐 Controle de AcessoValidação de carteirinhas com verificação de débitos

1.3 Requisitos do Sistema

  • Servidor: XAMPP / WAMP / LAMP
  • PHP: Versão 7.4 ou superior
  • MySQL: Versão 5.7 ou superior
  • Navegador: Chrome, Firefox, Edge (últimas versões)

2. INSTALAÇÃO E CONFIGURAÇÃO

2.1 Instalação no XAMPP

Passo a passo:
  1. Baixe ou copie todos os arquivos para: C:\xampp\htdocs\clube\
  2. Inicie o XAMPP e ative Apache e MySQL
  3. Acesse phpMyAdmin: http://localhost/phpmyadmin
  4. Crie o banco de dados: clube_sistema (utf8mb4_unicode_ci)
  5. Importe o arquivo SQL fornecido
  6. Acesse o sistema: http://localhost/clube/

2.2 Configuração Inicial

Criar usuário administrador:

  • Acesse: http://localhost/clube/criar_admin.php
  • Ou execute no phpMyAdmin o script de criação do admin

Configurar marca d'água:

  • Acesse: Configurações → Marca D'água
  • Envie a imagem do escudo do clube (PNG com fundo transparente)

Configurar cores das carteirinhas:

  • Acesse: Carteirinhas → Configurar Cores
  • Defina as cores para cada tipo de sócio
⚠️ Importante: Para renovação automática de convites, configure o Cron (tarefa agendada) para executar /cron/renovar_convites.php todo dia 1º do mês.

4. MÓDULO DE SÓCIOS

4.1 Cadastrar um Novo Sócio

Caminho: Cadastros → Sócios → Novo Sócio

Passo a passo:

  1. Selecione o Tipo de Sócio:
    • Proprietário: Cria uma nova família (chefia)
    • Dependente: Vincula a um proprietário existente
    • Contribuinte: Sócio contribuinte
    • Sócio Atleta: Sócio com perfil esportivo
  2. Se for DEPENDENTE:
    • Selecione o "Sócio Principal"
    • Escolha o parentesco
    • O título será copiado automaticamente
  3. Preencha os Dados Pessoais (Nome, CPF, Data nascimento, etc)
  4. Informe o Endereço
  5. Configure a Carteirinha (Convites, Foto, Tipo de identificação)
  6. Clique em "Cadastrar Sócio"

4.2 Gerenciar Dependentes

Caminho: Cadastros → Sócios → Clique no ícone 👥

4.3 Editar um Sócio

Caminho: Cadastros → Sócios → Clique no ícone ✏️

⚠️ Atenção: A exclusão é permanente. Recomenda-se desativar o sócio em vez de excluir.

6. MÓDULO DE CONVITES

6.1 Como Funciona o Sistema de Convites

  • Cada família (proprietário + dependentes) tem um total de convites por mês
  • Os convites são compartilhados entre todos os membros da família
  • Quando um membro usa um convite, desconta do total da família
  • A renovação ocorre automaticamente no dia 1º de cada mês

12. SOLUÇÃO DE PROBLEMAS

12.1 Erro ao Fazer Login

Solução: Verifique se o usuário existe no banco e se o Apache está rodando.

12.2 QR Code Não Aparece

Solução: Execute http://localhost/clube/recriar_carteirinhas.php para recriar todos os QR Codes.

12.3 Validação Retorna "Sócio não encontrado"

Solução: Verifique se o número do título está correto e se o sócio está ativo.

13. PERGUNTAS FREQUENTES

P: Como faço backup do sistema?
R: Copie a pasta clube e exporte o banco no phpMyAdmin.

P: O sistema funciona em celular?
R: Sim! É totalmente responsivo.

P: Os convites acumulam de um mês para o outro?
R: Não, são renovados mensalmente (dia 1º).

P: Dependentes usam os mesmos convites?
R: Sim, todos os membros da família compartilham o mesmo pool.

P: As senhas são seguras?
R: Sim, usamos hash bcrypt.
